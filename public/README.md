# Pasta public/

Arquivos estaticos servidos diretamente pela raiz do site.

## Logo

Salve o logo da marca como **`logo.png`** nesta pasta:

```
public/logo.png
```

O app referencia esse arquivo em `/logo.png` (ver `src/components/AuthCard.tsx`).
Formato recomendado: PNG com fundo transparente. SVG tambem funciona —
nesse caso, salve como `logo.svg` e ajuste o `src` no `AuthCard.tsx`.
